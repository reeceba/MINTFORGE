# MINTFORGE Worldwide Shipping Model

The marketplace supports worldwide physical-goods shipping.

## Seller shipping
- Worldwide shipping by default
- Flat-rate shipping or free shipping
- Country exclusions
- Processing time
- Seller-specific shipping rules

## Buyer addresses
- Full international country selection
- Full name
- Email
- Address line 1/2
- City
- State/province/region
- Postal/ZIP code
- Multiple saved addresses with a default address

## Orders
At checkout, the destination country resolves the seller's shipping rule. The final shipping amount and the exact shipping address are snapshotted onto the order so later listing changes do not alter existing orders.

## Security
Shipping totals must be calculated and verified server-side. Buyers cannot override seller shipping prices from the client. Seller access is restricted to listings/orders owned by the connected seller wallet.
